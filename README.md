# Transport Agentic Assistant

The repo contains agentic code which process bus transport data and provides answers and insights


Use the requirements file and do `pip install -r requirements.txt`


After that run the code with `python app.py`. This will run the application with a default question. If you want to add your own question write `python app.py <your question here>`

The code will give output to the command line and will also generate `trips_processed.csv` or `summary_data.csv` for your reference.
